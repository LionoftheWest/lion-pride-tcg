### admin_actions

Table. [admin] The admin audit log: one row per admin action (who, what, the target, before and after, why, where from, which action it undoes). admin_log_action writes it for the Admin view; the gift_admin_log trigger writes the admin gifts (reasons admin, event, launch_gift). Server only.

| Column | Type | Null | Default | Comment |
|---|---|---|---|---|
| `id` | bigint | not null |  | The action id. undo_of points at it. |
| `at` | timestamp with time zone | not null | `now()` | When the action was made. |
| `actor` | text | not null |  | Who made it: the admin (the Discord id from the bot or the studio), else balance_who for SQL. |
| `action` | text | not null |  | What was done, for example gift (gift_admin_log) or the Admin view action name. |
| `target_kind` | text | null |  | The kind of target, for example player (one member), players (many members), card, balance, settings. Null = none. |
| `target_id` | text | null |  | The target id as text (for player: players.id). Null for many targets (after.count and after.gift_ids list them). |
| `before` | jsonb | null |  | The state before the action as jsonb (for an undo). Null = not recorded. |
| `after` | jsonb | null |  | The state after the action as jsonb. For a gift: kind, title, amount, shards, count, gift_ids. |
| `reason` | text | null |  | Why: the text of the admin, or the gift reason (admin, event, launch_gift). |
| `source` | text | not null |  | Where it came from: studio (the Admin view), bot (an admin slash command), sql (the SQL editor or a script). |
| `undo_of` | bigint | null |  | The action that this action undoes (admin_actions.id), else null. An action is undone at most once (admin_actions_one_undo). |

- Primary key: `PRIMARY KEY (id)`
- Foreign keys: 
  - `admin_actions_undo_of_fkey` to [admin_actions](admin.md#table-admin-actions): `FOREIGN KEY (undo_of) REFERENCES admin_actions(id)`
- Check constraints: 
  - `admin_actions_action_check`: `CHECK ((length(TRIM(BOTH FROM action)) > 0))`
  - `admin_actions_actor_check`: `CHECK ((length(TRIM(BOTH FROM actor)) > 0))`
  - `admin_actions_source_check`: `CHECK ((source = ANY (ARRAY['studio'::text, 'bot'::text, 'sql'::text])))`
- Row level security: on. Policies: none
