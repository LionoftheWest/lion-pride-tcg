- Function: `event_reward_errors(p_item jsonb, p_where text, p_rank boolean)`
- Returns: `text[]`
- Security definer: no

[events] The errors of one reward item (per_member or a rank tier): packs 0-100, shards 0-100000, card_id, from and to 1-1000 for a tier, at least one reward. Empty = valid.

<a id="fn-event-row-errors-events"></a>

### event_row_errors(events)

- Function: `event_row_errors(p_e events)`
- Returns: `text[]`
- Security definer: no

[events] The errors of a candidate event row: key (format, unique), title, description, the times, the shapes with vars and theme (6-argument event_shape_errors), a Hunt that overlaps a scheduled or live Hunt event, and that each reward card exists. Empty = valid.

<a id="fn-event-shape-errors-text-jsonb-jsonb-jsonb-jsonb-jsonb"></a>

### event_shape_errors(text,jsonb,jsonb,jsonb,jsonb,jsonb)

- Function: `event_shape_errors(p_kind text, p_audience jsonb, p_rewards jsonb, p_rules jsonb, p_vars jsonb, p_theme jsonb)`
- Returns: `text[]`
- Security definer: no

[events] All shape errors of an event: the 4 shapes (kind, audience, rewards, rules) + vars (event_vars_errors) + theme (event_theme_errors). Empty = valid. event_row_errors and event_template_errors use it.

<a id="fn-event-shape-errors-text-jsonb-jsonb-jsonb"></a>

### event_shape_errors(text,jsonb,jsonb,jsonb)

- Function: `event_shape_errors(p_kind text, p_audience jsonb, p_rewards jsonb, p_rules jsonb)`
- Returns: `text[]`
- Security definer: no

[events] The errors of an event's kind, audience, rewards and rules (the shapes in events.sql; a modifier: audience everyone, rewards {}, rules {}; a hunt: audience everyone, rewards {}, rules {} or a tier). Empty = valid. The CHECK events_shape uses it; the Admin save uses the 6-argument form.

<a id="fn-event-step-bigint-timestamp-with-time-zone"></a>

### event_step(bigint,timestamp with time zone)

- Function: `event_step(p_id bigint, p_now timestamp with time zone DEFAULT now())`
- Returns: `jsonb`
- Security definer: no

[events] One step of one event: scheduled to live (a drop pays its start), live to ended at ends_at (trigger and rank pay the end), the catch-up of a live trigger event or a drop with late_joiners, and event_hunt_step for a live Hunt event. launch_cards: status only.

<a id="fn-event-template-errors-event-templates"></a>

### event_template_errors(event_templates)

- Function: `event_template_errors(p_t event_templates)`
- Returns: `text[]`
- Security definer: no

[events] The errors of a candidate template: name (1-80, unique), description, default_length (more than 0, at most 62 days), kind (drop, trigger, rank, modifier, hunt), the 6 shapes, the reward cards exist. Empty = valid.

<a id="fn-event-theme-errors-jsonb"></a>

### event_theme_errors(jsonb)

- Function: `event_theme_errors(p_theme jsonb)`
- Returns: `text[]`
- Security definer: no

[events] The errors of an event's theme: only name (1-40), color (#RRGGBB), art (an https URL, at most 500) and banner (1-120). Empty = valid. The CHECKs events_theme and event_templates_theme use it.

<a id="fn-event-tick-timestamp-with-time-zone"></a>

### event_tick(timestamp with time zone)

- Function: `event_tick(p_now timestamp with time zone DEFAULT now())`
- Returns: `jsonb`
- Security definer: no

[events] The pg_cron job event-tick (every minute since event_vars.sql): event_step for each scheduled or live event that started. One tick at a time (advisory lock). Returns the steps.

<a id="fn-game-pull-rates-timestamp-with-time-zone"></a>

- Returns: `jsonb`
- Security definer: no

[events] balance pulls with the live pull_rare_mult: every rate that is not normal x the factor, normal = 1 - their sum (scaled to add up to 1 if they would pass 1). Returns pack_size, rare_mult and rates.

<a id="fn-game-var-text-timestamp-with-time-zone"></a>

### game_var(text,timestamp with time zone)

- Function: `game_var(p_key text, p_now timestamp with time zone DEFAULT now())`
- Returns: `numeric`
- Security definer: no

[events] The value of one game variable at a time: the base from balance (or 1 for a factor), combined with the vars of every live event inside its window (multiply or max), the combined event part kept inside the limits, rounded for a whole variable. No live event = the balance value. Raises for an unknown key.

[events] Every game variable at a time, {key: game_var(key)}: the one call that the bot caches (F-1 PR 4).
