### events

Table. [events] One row per event (events.sql): key, kind (drop, trigger, rank, launch_cards), title, description, status (draft, scheduled, live, ended, cancelled), the window starts_at .. ends_at, audience, rewards and rules (jsonb; the shapes are in events.sql and checked by event_shape_errors). | Column | Type | Null | Default | Comment |
